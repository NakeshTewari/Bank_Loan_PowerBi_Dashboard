# Bank Loan Analytics Dashboard

## Overview
An interactive Power BI dashboard built to analyze bank loan performance, funded amount, repayment trends, and loan risk metrics.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- SQL
- Excel

## Dashboard Features
- Loan Application KPIs
- MTD & MoM Analysis
- Good Loan vs Bad Loan Analysis
- State-wise Loan Distribution
- Loan Status Monitoring
- Interest Rate & DTI Analysis
- Interactive Filters and Drilldowns

## Key Metrics
- Total Loan Applications: 38.6K
- Total Funded Amount: $435.8M
- Total Amount Received: $473.1M
- Good Loans: 86.18%
- Bad Loans: 13.82%
